Flaskとは？

Flaskの特徴

FlaskはPythonでWebアプリケーションを作ることができる軽量なフレームワークです。 シンプルな構造で初心者でも扱いやすく、 必要な機能を自由に追加できるのが特徴です。

Flaskのメリット
  • シンプルで分かりやすい
  • PythonだけでWeb開発ができる
  • 自由にカスタマイズ可能
  • 初心者でも学びやすい
制作内容

今回作ったプログラム

今回はCSVファイルを読み込み、 そのデータをWebページに表示するプログラムを作成しました。

特に、場所のデータをGoogleマップのリンクへ変換し、 ボタンを押すだけで地図を開けるように工夫しました。

できること
  • CSVデータの読み込み
  • Webページへのデータ表示
  • Googleマップとの連携
  • 条件分岐による表示変更
工夫した点

プログラムの工夫

  • CSVのデータをリストとして取得
  • 位置情報をGoogleマップURLに変換
  • 条件分岐で表示方法を変更
  • 見やすいWebページデザインを作成

データの内容によって表示を変えることで、 ユーザーが見やすいページになるよう工夫しました。

HTMLコード

データ表示部分

{% for data in mmlist %}
  {% if data[1] == "場所" %}
    {{ data[1] }}
  {% elif data|length > 3 and data[3] %}
    {{ data[1] }}
  {% else %}
    {{ data[1] }}
  {% endif %}
{% endfor %}

このコードでは、CSVデータを1つずつ取り出し、 条件によって表示方法を変更しています。
