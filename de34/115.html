筋トレメニュー＆食事提案アプリ

① このアプリとは

このアプリは、ユーザーの身長・体重・目的に応じて、 最適な筋トレメニューと食事プランを自動で提案するWebアプリである。 Python（Flask）を用いて開発し、初心者でも効率よく体作りができるように設計した。

② 作成したアプリの概要

ユーザーが情報を入力すると、BMIを自動計算し、 目的（増量・減量）に応じた筋トレメニューと必要なたんぱく質量を表示する。 また、食事メニューも同時に提案することで、 トレーニングと食事の両面からサポートできるようにした。

③ Python（Flask）コード

from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def index():
    if request.method == "POST":
        name = request.form["name"]
        height = float(request.form["height"])
        weight = float(request.form["weight"])

        bmi = weight / ((height/100)**2)

        return render_template("result.html", name=name, bmi=bmi)

    return render_template("index.html")

④ 実行画面（イメージ）

ユーザーが身長・体重を入力し、送信ボタンを押すと、 BMIが計算され、ユーザーごとに異なる筋トレメニューと食事プランが表示される。 画面はシンプルで見やすく、初心者でも直感的に操作できるようにデザインした。

⑤ 工夫した点

BMIを自動計算し、ユーザーごとに異なる結果を表示する点を工夫した。 また、筋トレメニューだけでなく食事内容も提案することで、 より実用的なアプリにした。 デザイン面ではカード形式を採用し、見やすさを意識した。
