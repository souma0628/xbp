Arduino 第1回 課題

① 目的

Arduinoにふれてみることを目的とする。 光センサーを使って、暗いときにLEDが点灯し、 明るいときに消灯するプログラムを作成する。

② 使用したもの

  • Arduino Uno
  • LED
  • 光センサー
  • 抵抗
  • ブレッドボード

>

③ 作成内容

センサーの値を読み取り、その値によってLEDのON/OFFを制御した。 暗いときにLEDが光るように設定した。

④ プログラム

int sensorPin = A1;
int ledPin = 13;
int threshold = 500;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int val = analogRead(sensorPin);

  Serial.println(val);

  // 🔥ここを修正（暗いときに点灯）
  if (val > threshold) {  // ← ここを「>」にする
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(500);
}

⑤ 結果・感想

センサーの値によってLEDの点灯を制御することができた。 閾値の設定によって動作が変わるため、調整が重要だと感じた。 今後は他のセンサーとも組み合わせて応用したい。 難しくて心がおれそうですが、頑張ります。
